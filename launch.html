🌐 Free Launch Guide

Get the current HP Clerk Prep website online with a Netlify netlify.app address first. You can add a custom domain later.

OPEN NETLIFY DROP →

1Download and unzip

Download the Step 25 ZIP from ChatGPT and extract it into one folder. The folder must contain index.html and the JSON files.

2Open Netlify

Create/sign in to your Netlify account, then open Netlify Drop. Netlify's current documentation says you can publish a site by dragging its project folder to the Drop zone.

3Drag the folder

Drag the extracted Step 25 folder into the Drop zone. Do not drag only one HTML file.

4Get your free URL

Netlify will provide a URL ending in .netlify.app. You can customize the project name from the Netlify dashboard if the name is available.

5Test everything

  1. Home page loads.
  2. Question Bank opens.
  3. Current Affairs opens.
  4. Previous Papers links work.
  5. 100Q Exam starts and timer runs.
  6. Dashboard receives your test result.
  7. Leaderboard shows your local result.
  8. Admin panel can edit local questions.

⚠️ Before calling it a real student platform

The current site is a static/browser prototype. Its admin data and student results are stored locally. Do not use it yet for real student accounts, passwords, payments, or sensitive personal information.

Next production step: connect secure authentication + database + server-side admin authorization.
